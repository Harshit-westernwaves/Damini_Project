File Format Requirements

All student records files must adhere strictly to the following 6-column specification:

1. Student ID Text / String

Alphanumeric identifier (e.g., STU001, CSE2023001).

2. Study hrs Float (0.5 - 12.0)

Average daily coursework and self-study hours.

3. Attendance Float (0.0 - 100.0%)

Class attendance percentage. Mandatory gate is 75.0%.

4. Previous marks Float (0.0 - 100.0)

Prior semester baseline examination score.

5. Assignment scores Float (0.0 - 100.0)

Continuous internal assessment and homework average.

6. Final performance Target (0.0 - 100.0)

Final semester evaluation score (Target prediction variable).

Missing Value Handling

If your CSV contains missing or duplicate records, use the Data Cleaning module next to impute or drop them safely.
